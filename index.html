AI MEMORY ARCHIVE

AI技術重現逝者生命
臺灣數位永生如何發展

【記者陳少凡、黃暐喬、陳雙、顏貝恩報導】

當 AI 開始模擬逝者的聲音、表情與記憶，死亡是否仍然是一個明確的終點？

什麼是數位永生？

透過逝者生前影像、語音與個人資料，AI 建立可互動的「數位人」，讓思念得以延續。

章節 1｜數位永生走進現實

音樂響起，伴隨俏皮幽默的步伐，曾經的秀場天王豬哥亮竟緩緩從側台走出，再次登上了螢光幕。2026年除夕夜晚上節目「民視第一發發發」，主辦方運用人工智慧技術重現已逝主持人豬哥亮的影像，讓現場主持人能夠與影像中的豬哥亮展開跨時空交談。影像中的豬哥亮，不但重現了他經典的主持風格，就連說話的神情、幽默風趣的主持口吻都被復刻。這樣高度擬真的再現，與近年逐漸盛行的「數位永生」概念相互呼應。

章節 2｜思念如何變成一種技術服務

打開手機，離世多年的親人站在手機螢幕裡和你打招呼。數位永生透過收集逝者生前留下的影像和語音，讓AI模擬親人的語氣、性格與記憶，將逝者的神韻重現，形塑成螢幕裡的「數位人」。目前臺灣少數提供數位永生服務的上丘智能總經理陳柏言表示，客戶主要期望透過創造數位人，彌補逝者無法參與人生重要時刻的遺憾。

章節 3｜臺灣發展困境：技術如何製作數位人

「數位永生並非由單一技術完成，而是透過 API 整合多種應用來實現。」陳柏言說明，製作一個數位人，需要客戶提供逝者的影像與至少一分鐘的語音素材，並建立專屬知識庫，包括個人背景、個性與說話習慣。素材會被導入嘴型同步、臉部動作同步、聲音克隆、語音辨識、文字轉語音以及大語言模型等系統，最終創造出具有互動能力的數位人。

章節 4｜語言模型與文化落差

台灣超級頭腦資訊科技工作室負責人周子豪指出，語言模型的擬真度會直接影響使用者的真實感受。即使能夠直接導入中國的語言模型，仍可能因文化與慣用語差異，讓使用者產生明顯落差。此外，陳柏言進一步說明，國語系統仍能透過中國技術調整，但台語的語言系統訓練才是最大挑戰。由於台語屬於較少被開發的語言，目前市場缺乏相關資源，也限制臺灣推動數位永生技術的發展。

語言模型與文化落差

中國模型可用，但慣用語與文化語境會造成真實感落差。

台語訓練困難

台語資料量少，商業開發誘因不足。

即時互動硬體成本

需要穩定網路、高效能設備與多系統串接。

章節 5｜中日韓差異與倫理問題

國立政治大學實驗教育中心博士後研究員兼執行長徐勇康指出，中國數位永生產業發展快速，與科技產業支持、殯葬企業商業化，以及較少受到復活死者與鬼神禁忌影響有關。日本則因少子化與高齡化社會，對孤獨、死亡與陪伴需求更加敏感。韓國影視作品《夢境》也呈現人類透過虛擬世界與逝者重逢的想像，引發「安慰」與「依賴」之間的倫理討論。

章節 6｜法律缺口

國立政治大學法律學系沈宗倫教授說明，以臺灣法律來說，數位永生運用逝者在世時的影片、照片或聲音，死後已難以透過人格權保障。目前較能處理的是影像、聲音或作品的著作權問題。若未來能在生前明確設定授權範圍、使用年限與繼承機制，將有助於降低死後人格被濫用的風險。

人格權

臺灣人格權主要保障有生命的人，死後保護不足。

著作權

影像、聲音、作品可能透過著作權處理。

死後授權

可思考生前授權、使用年限、親屬管理與撤回機制。

章節 7｜不只復活死者

「數位永生不該只用於復活往生者。」徐勇康表示，臺灣數位永生產業若只停留在復甦死者，市場會限縮在少數客群。陳柏言也指出，團隊目前正朝向智慧陪伴與長照服務發展，除了聊天功能，也預計整合健康提醒、即時精神狀態分析與智慧通報。未來數位人可能不只是逝者的替身，也可能成為陪伴、照護與娛樂產業的新工具。

結語

數位永生與數位人為社會提供了新的選擇。人們可以不用它，但當有人需要時，它也可能成為面對失去、整理記憶與重新理解死亡的一種方式。技術如何被使用，仍取決於人如何為它設下界線。
